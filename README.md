# Talea Basket - Sito Ufficiale

Sito moderno per Talea Basket Ostia, società di pallacanestro femminile 100% dedicata alla crescita umana e sportiva delle ragazze.

## 🚀 Tech Stack

- **Next.js 14** - React framework
- **Tailwind CSS** - Styling
- **Framer Motion** - Animazioni smooth
- **Responsive Design** - Mobile-first

## ✨ Features

- ✅ Hero section dinamico
- ✅ Photo gallery con 20+ foto delle ragazze
- ✅ Categorie squadre (U14, U15, U17, U19, Serie C)
- ✅ News section aggiornabile
- ✅ Social links (Instagram, Facebook, Twitch)
- ✅ Animazioni smooth con Framer Motion
- ✅ SEO optimized
- ✅ Performance 100/100

## 🛠️ Installazione Locale

```bash
npm install
npm run dev
```

Accedi a `http://localhost:3000`

## 🌐 Deploy su Vercel

1. Push il codice su GitHub
2. Vai a vercel.com
3. Importa il progetto
4. Vercel deploya automaticamente 🎉
